# Decisions log: massing take-off and calculation template

Methodology decisions behind `takeoff/` and `calc/`. **Confirmed** means agreed by the office WLCA lead.
**Assumed** means a working default that still needs confirming. **Open** means not decided yet.
Drafted by an AI agent (Claude) from the working sessions; review before relying on it.

## Calculation template (`calc/`)

| # | Decision | Status |
|---|---|---|
| C1 | Workbook is generated by a script from three inputs (take-off export, build-up library, benchmark table) and keeps live formulas, so factors and inputs can be changed in Excel. No project or library data in this repo | Confirmed |
| C2 | Baseline A1–A3 factors: the library adopts the ETPP-28 (Arup 2025) baseline reference table where it overlaps, with the source kept per material (library v0.8) | Confirmed |
| C3 | Unitised curtain wall: build-up from the ETPP-28 unitised curtain wall bill of materials (per m² of façade incl. spandrel). CWCT method: factory assembly, transport to fabricator and fabrication waste in A3 (PS 5.1.4: offsite manufacturing waste belongs in A1–A3). CWCT site assembly is not added, because the A5.2 site lump covers it | Confirmed |
| C4 | Façade route switch on Project. "Unitised curtain wall" sends the opaque façade rows (the take-off's opaque build-up code, 2.5.1) to the curtain wall build-up and reports them in 2.5.2. Soffits are not routed | Confirmed |
| C5 | Benchmarks for elements not taken off: kgCO2e/m² GIA by use class (PS 4.5.2 method 2). The source covers shell & core + Cat A (building-related FF&E); Cat B loose items are excluded | Confirmed |
| C6 | Site lumps per m² GIA: A5.1 35 (existing GIA demolished), A5.2 40, C1 12. The PS Table 25 reading (25% of A5.2) would give C1 = 10 | Confirmed |
| C7 | Benchmark C1 shares are excluded by default, so C1 is not counted twice (element shares plus the whole-building lump). Switchable on Project | Assumed |
| C8 | A5.3 = waste rate × (A1–A3 + A3 offsite + A4 + C2–C4 of the wasted material). The rate is used directly, as in PS 5.1.4 and the office dwelling workbook. A layer can carry its own site rate | Assumed |
| C9 | B4 replacements = ROUNDUP(RSP / life) − 1 (PS 5.2.4: whole replacements, rounded up). **This differs from the dwelling workbook, which rounds down.** Curtain wall frames are 60 years; glass follows Table 20 (35 years), so it is replaced once | Assumed — differs from the dwelling workbook |
| C10 | End of life of replaced items goes in C2–C4 (× (1 + replacements)), as in the dwelling workbook | Assumed |
| C11 | A4 per material uses lorry loads: ROUNDUP(max(mass/payload, volume/capacity)) × Table 17 road km × (c1 + c2). DEFRA factors include the return leg, so the empty running factor is 1.0. The sea leg is per tonne-km, because ships are not loaded like lorries (the dwelling workbook's per-load sea factor does not scale) | Assumed |
| C12 | C2 uses loads to processing, EfW and landfill × distance × 2 × the 50%-laden factor (dwelling workbook). The Table 26 distances are placeholders (50 km) until the site is known | Assumed — set per site |
| C13 | C3/C4 per Table 23 route (PS 5.6.4 / 5.6.5). Landfill share × Table 28 → C4 (superseded the 16/10 reading that left C3 at 0). Reused + recycled share: EPD processing data where the library gives it, otherwise the PS fallback, the landfill default (Table 28), as a C3 stand-in. A material with no route counts as 100% landfill. Library C3/C4 values replace the defaults and must already be adjusted to the project route shares (dwelling-workbook lessons: apply the route share once, and never charge the landfill share in both C3 and C4) | Confirmed (XW 16/10/2026) |
| C13b | Bio-based materials follow the Table 23 split like any other material (e.g. engineered timber 5% reuse, 35% recycling, 59% incineration, 1% landfill). The Table 28 wood factor is fugitive methane from landfill, so it applies to the landfilled share only, in C4, on top of the biogenic CO2 released (as in the PS 5.6.5 worked example). The reused / recycled share takes the inert factor as its processing stand-in; Project switch charges the wood factor instead | Confirmed (XW 16/10/2026) |
| C13c | Incineration share × fossil CO2 on combustion (library Materials col W: EPD C3 for incineration where known, else carbon mass fraction × 44/12, tagged [ASSUMED]; bio-based 0). Reported in C3 under the PS UK simplification (Table 27 plants treated as energy recovery), with a note on the dashboard that R1 is assumed; Project switch "Disposal" moves it to C4. A-C is the same either way | Confirmed (XW 16/10/2026) |
| C13d | D1 energy recovery = -incinerated share × Table 27 electricity (biomass for bio-based, otherwise non-biomass, kWh/t) × grid factor, electricity only (PS Annex K example 2c). Grid factor = the latest DESNZ UK electricity generation factor (excl. T&D), kept in the library REF_T27_D1 and updated each June. A library D value replaces this estimate | Confirmed (XW 16/10/2026) |
| C13a | Biogenic carbon: never in A1-A3 / A1-A5 (upfront), reported separately alongside them; included in A-C as storage in A1-A3 and release at end of life (PS glossary, Appendix N), which net to zero over the life cycle. No contingency on biogenic carbon | Confirmed (XW 16/10/2026) |
| C14 | D is a memo only, never in A-C: per-kg values for metals where the library has them, D1 energy recovery for incinerated shares (C13d), 0 elsewhere. Concrete D values in the source were not adopted | Assumed |
| C15 | Contingency: PS Table 10 percentage (15% at RIBA 0–2) on A–C as a separate row; not on D or biogenic carbon | Assumed |
| C16 | Modelled layers whose element group is benchmarked are dropped, so there is one method per element (BR-14) | Confirmed |
| C17 | Scope coverage in QA: any expected element with neither a quantity nor a benchmark is a GAP flag (PS 4.4.1). The pilot gaps are now covered by the allowances below (G1–G7) | Confirmed |
| C18 | Rows that rest on an office assumption carry `[ASSUMED]` at the start of their notes. The workbook marks them (Takeoff column Z), counts them in QA and shows their share of A1–A5 in the Results headline | Confirmed |

## Scope-gap allowances (take-off v0.8)

All of these run on office assumptions until project information replaces them: drawings, model quantities or figures supplied by the engineer or the user. Each rule takes the best source available, in this order: supplied (`source: "supplied"`), then drawing or model, then assumption. Rows that still rest on an assumption are tagged `[ASSUMED]`.

| # | Decision | Status |
|---|---|---|
| G1 | Stairs (2.4): count, flights, treads, width and going come from the plan drawing. The plan extractor v0.2 reads treads as thin rectangles; runs of 4 or more make a flight, and flights within 1 m make a stair. The stairs are in-situ RC, with the waist and landings assumed at 0.20 m. The volume per storey scales with storey height. Every storey except the top one is climbed | Assumed (geometry from drawing) |
| G2 | Edge beams (2.1.2): a 400 × 350 downstand on every slab edge from level 1 up, plus the top roof edge (the larger of the storey's perimeter and the perimeter of the storey below). Transfer structures are not assumed | Assumed |
| G3 | Louvres (2.6): 50% of the façade on plant levels above ground (from the schedule's Use column), taken out of the opaque façade | Assumed |
| G4 | Entrance doors (2.6): 2 entrances × 15 m², taken out of the glazed façade | Assumed |
| G5 | Other roof elements (2.3): an allowance per m² of roof covering plant supports, hatches and outlets | Assumed |
| G6 | Inverted roof (2.5.3) and insulated soffit (2.5.1): placeholders adapted from the residential library types until there are practice details | Assumed |
| G7 | Not yet allowed for: guarding and balustrades, lift pits | Open |

| D4 | Office settings (library, benchmarks, targets, branding, façade list, defaults) live in one JSON file kept by the carbon team; relative paths resolve against the file, so one file serves every user's OneDrive | Confirmed |
| D5 | Plans: read from Rhino layers (true scale, any position; imported DWG/DGN or .3dm linework) is the default route (`takeoff/wlca_plan_rhino.py`); the PDF plan extract stays as the fallback. The Rhino route reproduced the PDF reading of the pilot floor (columns and stairs identical; core walls 137 m at ≈290 mm vs 144 m at 268 mm from the PDF pens) | Confirmed (XW 16/10/2026) |
| D6 | Punched façades take a window build-up per m² of window (glazed area = share × glazing ratio × net façade), reported to RICS 2.6. Office types: aluminium (ETPP EWS-02A) and timber-aluminium (ETPP EWS-02B); PVC not offered (ETPP data "tbc"). The window carries frame, DGU, gaskets, thermal breaks, brackets, head/sill flashings and lintel (PS App M). Rates are per m² of window opening (frame + glass), the area the take-off gives: the ETPP sample is 6 m² at 50:50 WWR, so 3.0 m² of opening holding 2.4 m² of DGU (80% vision) - window items ÷ 3.0 (corrected 16/10/2026 from ÷ 2.4, which was 25% high). The glazing ratio entered for a punched type is the window-to-wall ratio on openings, frames included. A façade type may share a wall build-up with another and differ only in its window (`id` in the office settings). Earlier the curtain wall build-up stood in for windows: similar A1-A3 per m² (≈165 vs ≈160 aluminium), but less glass per m², so it understated glazing replacement (B4) | Confirmed (XW 16/10/2026) |
| D7 | Window service life follows the CWCT / ETPP approach, as for the curtain wall: frame, gaskets, brackets, flashings and lintel 60 years; DGU 30 years (PS Table 20 windows) | Confirmed (XW 16/10/2026) |
| D8 | Stainless steel (lintels) keeps the library factor (global average, CHECK) until a supplier EPD is chosen; ETPP used a lower ICE value (≈6 kgCO2e/m² of window difference) | Confirmed (XW 16/10/2026) |
| D9 | Plan reader rules: core walls = closed outlines or hatches 100–500 mm thick (length = area ÷ thickness, thickness from the outline); columns = circles 0.2–1.5 m (squares only if enabled); stairs = tread rectangles grouped into flights as in the PDF extractor, read in the plan's own orientation; treads are never walls. Only shapes inside the floor plate count (largest closed outline on the wall layer). The file's unit header is checked against the shapes - a DWG said millimetres for metre coordinates - and a correction is applied and reported | Confirmed (XW 16/10/2026) |
| D10 | Plan layers fill themselves: office name patterns first (`plan_layer_patterns` in the office settings), then the layer with the most walls / columns / treads. The designer checks the proposal and the highlighted objects, and changes a layer only if it is wrong | Confirmed (XW 16/10/2026) |
| D11 | Core walls measured on a plan are scaled to their measured thickness (m² of the 250 mm build-up × t / 0.25), with a warning to check the thickness with the engineer - until the library has a build-up per wall thickness. Applies to the PDF route too | Confirmed (XW 16/10/2026) |

## Operational energy and water (B6 / B7, calculation template)

| # | Decision | Status |
|---|---|---|
| O1 | B6 needs a predictive energy model (PS 5.3: CIBSE TM54 or equivalent, never Part L): annual kWh by fuel per option (grid electricity, gas, district heat, PV used on site, PV exported). | O2 | RICS factor set 1, both scenarios always reported (PS 4.11.4).
